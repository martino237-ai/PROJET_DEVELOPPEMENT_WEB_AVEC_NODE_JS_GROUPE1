Description du projet :
Projet COPR325 : Conception et Développement Web avec Node.js
Le projet consiste en une application web de gestion d'une boutique e-commerce. 
L’application comporte :
- Un backend Node.js + Express connecté à une base de données MySQL.
- Un frontend React.js pour l’interface utilisateur.
- Gestion complète des produits : ajout, modification, suppression, affichage.
- Gestion complète des commandes : ajout, modification, suppression, affichage.
- Gestion complète des utilisateurd : inscription,connexion.
- Gestion des commandes : acceptation, refus, suivi du statut.
- Authentification utilisateur avec JWT.
- Interface responsive et moderne avec boutons, cartes, badges de statut.
- Téléversement d’images pour les produits.

Guide de test du projet :

1 Préparer l’environnement
- Installer Node.js et npm
- Installer MySQL
- Installer Git
- (Optionnel) Installer Postman pour tester les API

2 Cloner le dépôt Git
git clone https://github.com/martino237-ai/PROJET_DEVELOPPEMENT_WEB_AVEC_NODEJS_GROUPE1.git
cd <nom-du-repo>

3 Installer les dépendances
- Backend : cd backend && npm install
- Frontend : cd frontend && npm install

4 Configurer la base de données
- Créer une base MySQL nommée 'fournitures_db'
- Importer le script SQL fourni avec la commande :
  mysql -u <utilisateur> -p fournitures_db < mystore.sql
  (Remplacer <utilisateur> par votre nom d’utilisateur MySQL)
- Vérifier que les tables et données sont bien créées
- Modifier le fichier bd.js avec vos identifiants MySQL (host, user, password, database)

5 Lancer le serveur backend
- cd backend
- node start 
- Vérifier que le serveur affiche : Serveur démarré sur le port 5000

6 Tester les API avec Postman (optionnel)
- GET /api/produits : lister tous les produits
- POST /api/produits/ajouter : ajouter un produit
- PUT /api/produits/modifier/:id : modifier un produit
- DELETE /api/produits/supprimer/:id : supprimer un produit
-commandes...



7 Lancer le frontend React
- cd frontend
- npm start
- Vérifier l’ouverture de http://localhost:3000
- Tester les sections :
  * Mes fournitures : affichage, modification, suppression
  * Ajouter produit : ajout via formulaire
  * Commandes : acceptation/refus
  * Déconnexion : retour à la page de connexion

8 Vérifier les erreurs courantes
- 500 Internal Server Error : problème de connexion à MySQL
- 404 Not Found : URL incorrecte ou route manquante
- React key warning : vérifier que tous les éléments listés ont un key unique
